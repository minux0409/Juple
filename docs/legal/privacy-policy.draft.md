## 1. Juple이 처리하는 정보
**계정·인증**
- 로그인은 Microsoft Entra External ID를 통해 이루어지며 [REVIEW REQUIRED: 활성화된 방식 - 이메일/Google/Apple]. Juple 서버는 로그인 제공자의 식별 값(테넌트·사용자 식별자)만 계정과 연결하고 **이메일 주소는 저장하지 않습니다.** 이메일 등은 로그인 제공자가 처리합니다.
- Juple이 만드는 값: 무작위 **Juple ID**, 선택 입력 **닉네임**, 선택 **프로필 사진**, 언어와 시간대.

**직접 저장·입력하는 콘텐츠**
- 저장한 링크의 주소, 제목, 메모, 미리보기 이미지 주소, 직접 올린 사진.
- 컬렉션 이름·아이콘·색·사진, 컬렉션 잠금 비밀번호(복원 불가능한 해시로 저장)와 공유 접근 비밀번호.
- 친구, 친구 요청, 친구에게 남기는 비공개 메모, 초대·참가 요청, 댓글, 좋아요, 이모지 반응.
- 고객센터 문의 내용과 답변.
- 최근 연 링크 기록(내 기기에서 지울 수 있음).

**링크 정보 가져오기:** 링크를 저장하면 서버가 해당 주소의 **공개된** 페이지에서 제목·대표 이미지를 가져올 수 있습니다. 확인할 수 없는 정보는 추측하지 않고 직접 입력하도록 합니다.

**공유·협업:** 컬렉션을 공유하면 참여자는 컬렉션과 그 안의 링크, 제목, 내가 추가한 사실(닉네임 또는 Juple ID), 프로필 사진을 볼 수 있습니다. **공개 링크**를 켜면 링크를 아는 누구나 컬렉션 이름과 링크의 제목·주소·자동 미리보기를 볼 수 있으며 메모, 업로드한 사진, 추가한 사람은 공개되지 않습니다. 공유 비밀번호를 설정할 수 있습니다.

**푸시 알림:** 알림을 받으려면 기기 식별 값(앱 설치 ID)과 푸시 토큰, 언어를 서버에 등록합니다(Google Firebase Cloud Messaging 사용). 알림 기록은 앱 안의 알림 목록에 저장됩니다.

**결제(Google Play):** 결제는 Google Play가 처리하며 Juple은 카드 정보를 받지 않습니다. 구독 확인을 위해 구매 토큰(암호화하여 저장), 상품, 상태, 만료일 등 구독 정보를 처리합니다. 무료 체험 중복 방지를 위해 로그인 식별 값에서 만든 변환값(해시)과 체험 기간을 저장합니다. [REVIEW REQUIRED: 구독 프로그램 시작 전까지는 체험·결제 처리가 비활성입니다]

**운영 데이터:** 서버 로그(요청 처리 결과, 오류, 내부 식별자)를 최대 30일 보관합니다. 앱 사용 통계·광고·행동 추적은 하지 않습니다. [REVIEW REQUIRED: 충돌 보고 도구를 도입하면 이 항목을 갱신]

## 2. 이용 목적
서비스 제공(저장·정리·공유·알림), 계정과 보안(본인 확인, 부정 이용 방지), 구독 확인과 복원, 고객 문의 대응, 서비스 안정성 확인.

## 4. 보관과 삭제
- 계정이 있는 동안 위 정보를 보관하며, 사용자가 링크·컬렉션·사진·댓글을 지우면 해당 정보가 삭제됩니다. 삭제한 링크는 **삭제 이력**에 최근 100개까지 보관되며 직접 영구 삭제하거나 비울 수 있습니다.
- **계정 삭제:** 앱 안에서 직접 삭제할 수 있으며(`/account-deletion` 참고) 프로필, 링크, 컬렉션, 사진, 친구, 알림, 문의, 댓글 등이 삭제됩니다. 다만 아래는 남습니다.
  - 구독 구매 기록(프로필과 분리): 암호화된 구매 값은 구독 종료 후 180일, 나머지 최소 정보는 구독 종료 후 최대 5년 **[REVIEW REQUIRED: 5년 - 법률/회계 검토]**
  - 무료 체험 중복 방지용 해시와 체험 기간: 체험 종료 후 24개월(진행 중인 체험은 삭제하지 않음) **[REVIEW REQUIRED]**
  - 로그인 제공자에 있는 계정 정보: 제공자 정책에 따르며 Juple 계정 삭제로 지워지지 않음 **[REVIEW REQUIRED]**
  - 서버 로그: 최대 30일
  - 앱 내 알림 기록: 생성 후 90일
  - 휴지통(삭제 이력)의 링크: 삭제 후 30일(사용자당 최대 100개)
  - 삭제한 컬렉션과 병합 되돌리기 기록: 삭제 후 30일
  - 푸시 알림용 기기 토큰: 마지막 사용 후 180일
  - 결제 알림 처리 기록: 처리 후 90일
